Search a list from the add box: what you type narrows it, ticked items included, with the words in any order. A name typed on its own gets the amount it had last time, and adding something ticked off brings it back. A list can have a default area, set in Manage areas, and "No area" on an item now works. The app opens on the list you used last, which Settings can turn off, and has a Text size setting.

Remembered amounts need version 1.11 of the Shopping List server app, and default areas 1.12.
