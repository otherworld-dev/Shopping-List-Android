Search a list from the add box: what you type narrows the list, ticked items included. The app opens on the list you used last, which you can turn off in Settings, and Settings has a Text size choice. A list can have a default area for items no keyword places, set in Manage areas. A name typed on its own gets the amount it had last time, and adding something ticked off brings it back.

Remembered amounts need version 1.11 of the Shopping List server app, and default areas 1.12.
